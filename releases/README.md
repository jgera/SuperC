# SuperC Release Archives

Pre-compiled 64-bit Windows portable releases (`.zip`) can be downloaded directly from the GitHub Releases page:

👉 **[Download Latest SuperC Release on GitHub](https://github.com/jgera/SuperC/releases/latest)**

### Release Files:
Each release archive contains:
* `SuperC-Launcher.exe` - Floating Quick Launcher (`Ctrl + Space`)
* `c.exe` - Windows Run (`Win + R`) Command Runner & Math Engine
* `register.bat` - 1-Click Windows Run registration script
* `unregister.bat` - Unregistration script
* `app.ico` - Application icon
* `README.md` & `LICENSE`
